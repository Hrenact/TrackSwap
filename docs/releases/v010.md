# TrackSwap v010

v010 重点加入文件管理与可恢复的数据维护流程，并带来无需实体头显的虚拟 HMD、独立 VR 视图和通用手动位姿来源。

## 当前改动

- 新增“设置 → 文件管理”，集中显示 TrackSwap 创建或使用的文件、实际保存位置、是否位于安装目录内，并可快速定位。
- 文件管理底部新增独立的“重置数据”和“预卸载准备”卡片：前者清空用户数据并保留 SteamVR 集成，后者一并移除 TrackSwap 驱动、应用登记和位姿覆盖；两种操作均不会自动启动卸载器或删除程序文件。
- TrackSwap 自有可变数据默认集中到程序目录下的 `UserData`；当安装目录不可写时，明确回退到 `%LOCALAPPDATA%\TrackSwap`。
- 检测到 v009 及更早版本的数据时继续使用旧目录，直到用户主动迁移。迁移使用同盘暂存、配置校验与重启切换，并保留原目标内容；后续清理只删除已识别的 TrackSwap 文件。
- 新增完整配置导出与覆盖导入。导入前校验备份、二次确认并创建自动回滚副本；备份可能包含物理设备路径，因此界面会提示不要公开分享。
- SteamVR 配置备份集中到 `UserData\Backups\SteamVR`，不再继续在 SteamVR 配置目录旁散落新备份；已有备份可随旧版数据迁移。
- 新增“输出为虚拟头显”运行模式：使用物理位姿来源驱动一只 `TRKSWAP-HMD`，支持拆分来源、局部偏移、来源隐藏与 3D 预览，并通过虚拟显示重定向接收 SteamVR 最终合成画面。启用或停用需要完全重启 SteamVR。
- 新增独立的 TrackSwap VR 视图：支持双眼、左眼、右眼、固定输出尺寸、始终置顶、无边框全屏和 PNG 截图。查看器通过三缓冲 GPU 共享纹理读取最新帧，关闭或显示变慢不会反向阻塞 SteamVR。
- 虚拟头显的输出设备行提供 SteamVR 房间设置与 VR 视图入口，并使用 SteamVR 自带的通用 HMD 回退模型。
- 普通卸载继续清理 TrackSwap 的 OpenVR 驱动、应用登记、自动启动与静态映射，但保留运行时创建的 `UserData`，方便重装后继续使用。
- 新增 SteamPipe Preview 构建入口、depot 文件审计、Steam 安装/卸载集成脚本与上架检查清单。Steam 内容明确排除 `UserData`、PDB 和开发者本机路径。
- 所有运行模式新增显式“手动位姿”来源，以默认位于原点的持久化站立空间绝对位姿运行，不再依赖实体设备；虚拟头显也不再依赖空来源触发的隐式引导位姿，手动位姿与实体来源局部偏移相互独立。
- 正式发布构建现在会运行 Protocol、Runtime、文件迁移/备份、手机震动诊断、安装注册和原生驱动测试。

## 升级提示

- v010 不会自动搬动旧配置。请进入“文件管理”检查当前位置并主动执行迁移。
- 确认迁移后的路由和设置正常后，可选择清理旧版文件；未知文件不会被删除。
- SteamVR 运行时不能执行数据迁移或安装集成变更，请先完全退出 SteamVR。
