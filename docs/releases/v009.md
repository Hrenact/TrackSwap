# TrackSwap v009

v009 重点补齐 Runtime 独立运行能力、实体来源隐藏与拆分位姿来源，并扩展 OSC 控制器输入、震动反馈、诊断和状态显示。

## 位姿路由与设备呈现

- 新增“拆分来源”。每条配置可分别选择位置来源与旋转来源；两者从同一批 OpenVR 位姿采样，组合后再应用统一的局部刚体偏移，任一来源失效时输出会明确失效。
- 新增默认关闭的“隐藏物理位姿来源设备”。Runtime 保存请求，原生驱动执行位姿钩子；失败时保持原始物理位姿，不会让 TrackSwap 输出跟随隐藏位移，并对 HMD 与潜在注入冲突单独警告。
- 替换模式的 `TRKSWAP-PROXY-XX` 改为内部 Tracking Reference 载体并使用空渲染模型，不再作为额外可穿戴 Tracker 暴露给游戏或校准工具。
- 补齐虚拟控制器的 `/pose/openxr_aim` 与 `/pose/openxr_grip`，并采用左右手镜像的 Oculus Touch 兼容局部位姿。
- 更新左右虚拟控制器的 SteamVR 状态图标；保留 TrackSwap 独立设备身份，并为不同连接状态生成一致的图标族。

## Runtime 与可靠性

- 配置对静态映射的协调、待删除完成、孤立代理清理与失败重试全部迁入 Runtime；关闭 UI 后，路由、输入、设备隐藏和待处理维护仍会继续工作。
- 修复 SteamVR 会话结束时错误关闭手动启动 UI 的问题，并完善“跟随 TrackSwap / 跟随 SteamVR”两种 Runtime 生命周期。
- 修复普通路由与虚拟控制器快照交错时，设备隐藏请求可能被另一类空快照短暂清除并造成物理设备偶发闪回的问题。
- 新增隐私收敛的诊断包：记录版本、健康状态、配置验证摘要和 TrackSwap 相关日志，不导出原始配置、设备序列号或完整 SteamVR 日志。

## OSC 输入与震动

- OSC 设置改为独立的地址、接收端口和发送端口；移除无信号自动复位，避免用户保持静止姿势时输入被清空。
- 新增左右手独立的 OSC 震动反馈地址、实时滚动波形预览、可辨识的测试序列，以及用于手机浏览器实机验证的独立本地诊断工具。
- 新增 OSC 拇指与食指触摸辅助，支持“默认接触 / 默认抬起”和按住参数临时反转；真实按钮、摇杆和模拟输入保持更高优先级。
- 接收器会先合并一个 UDP 包中的全部参数，每只手只在最终状态发生变化时发送一次驱动快照；重复保活值仍刷新连接健康状态，但不再制造冗余 IPC。
- 底部 OSC 状态在接收端口冲突或本地发送失败时变为红色，并通过悬停提示分别列出问题；普通等待信号仍为橙色。

## XInput 与界面

- 重做模拟输入触发阈值控件：支持扳机实时填充预览、独立拖拽标记与固定默认值标记，并保留 5%–95% 的可选范围。
- 将 XInput 输入反馈整合进按键图标背景；摇杆图标直接作为二维移动指示，摇杆坐标与按下状态保持分离。
- 优化左右绑定、触摸辅助、震动映射、下拉候选预览和重置确认，修复下拉框高度、箭头预留、滚动穿透与设置返回页面等问题。
- 新增贯穿窗口底部的紧凑状态栏，集中显示 SteamVR、Runtime、OSC、XInput 与设备隐藏健康状态。

## 第三方与验证

- 实体来源隐藏实现参考 OpenVR Space Calibrator 的公开架构并使用固定版本 MinHook；许可证与来源已记录在 `THIRD-PARTY-NOTICES.md`。
- XInput 按键素材继续使用 Xelu Free Controller Prompts 的 CC0 Xbox Series 子集。
- 完成 Windows x64 托管项目、原生驱动、协议、Runtime、OSC、XInput、设备隐藏、拆分位姿、静态映射维护与安装包构建验证。
