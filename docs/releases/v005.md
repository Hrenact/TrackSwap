# TrackSwap v005

v005 聚焦于日常使用体验、设备管理和安装部署，并进一步完善 SteamVR 会话生命周期。

## 主要变化

- 全面改造为紧凑的 Dark Utility 界面，加入深色原生标题栏、统一的深色弹窗与系统提示音，并重新组织设置页和配置侧栏。
- 新增 TrackSwap 应用图标及虚拟代理状态图标；虚拟代理继续使用不可见渲染模型，不再显示误导性的 GenericTracker 模型。
- 3D 预览现在使用物理来源与最终目标模型，支持平移、旋转、缩放和重置视图，并修正组件模型及纹理映射。
- 新增本地设备记录与低频实时刷新。选择器统一使用“在线/离线”状态，能保留断开的实体设备，并可在设置中查看或清理记录。
- SteamVR 的头显、左手和右手角色目标默认隐藏，可在高级选项中显式开放；所有冲突、自引用与循环验证仍然生效。
- 新增 Runtime 启停行为，可选择跟随 TrackSwap 或 SteamVR；可选让 TrackSwap UI 随 SteamVR 启停，并在退出前完成待删除或待映射工作。
- 停用、删除、新建与修改目标的静态映射状态得到统一处理；SteamVR 运行期间保存的更改会在其完全退出后自动协调，无需再次点击应用。
- 新增 Windows 安装器和完整卸载器。安装器注册驱动与 SteamVR 应用清单；卸载器清理 TrackSwap 程序、用户数据、虚拟代理映射、应用注册和产品生成的备份。

## Pico 手柄兼容性提示

具体设备之间的 `TrackingOverrides` 属于实验性用法，是否生效取决于 SteamVR 版本和目标设备驱动。Valve Index Knuckles 在本次测试中可以作为明确实体目标正常跟随；Pico 手柄仍可能忽略覆盖或无法跟随。

这不代表所有 Pico 设备或驱动版本必然失败。使用 Pico 目标时，请在 SteamVR 中目视确认跟随结果，并对照 TrackSwap 预览和状态。TrackSwap 不会在实体目标失败时静默切换到 SteamVR 角色目标。

## 安装与升级

- 推荐下载 `TrackSwap-v005-setup-win-x64.exe`，安装和卸载前必须完全退出 SteamVR。
- 安装器目前未进行代码签名，Windows 可能显示 SmartScreen 警告；可使用随附 SHA-256 文件核对下载内容。
- 仍提供完整 ZIP，供便携使用或手动部署。
- 完整卸载会删除 `%LOCALAPPDATA%\TrackSwap` 中的配置、校准档案和设备记录，请在需要时提前备份。

- Windows x64 Release 构建、Protocol 测试、Runtime 测试和原生驱动位姿测试。
- 多路由独立跟随、局部偏移、来源断开重连与待处理映射协调。
- SteamVR/Runtime/UI 启停组合及 SteamVR 启动应用行为。
- 实体设备模型、组件纹理、虚拟代理图标和隐藏渲染模型。
- 在真实机器上完成安装、首次启动、卸载及零残留审计，并验证 C 盘程序数据与 D 盘 SteamVR 配置的跨盘写入。
