# TrackSwap VR v012

v012 重点完善虚拟设备兼容性、设备查看体验与发布合规检查。

## 新增与改进

- 新增设备查看窗口，可查看当前连接到 SteamVR 的设备模型、位姿和可用属性。
- 设备查看同步 SteamVR 环境背景，并加入地面参考网格、设备选择描边、技术信息与一键复制。
- 设备查看跟随屏幕刷新率，前台最高 240 Hz，最小化时降至 10 Hz；配置内 3D 位姿预览保持 30 Hz。
- 虚拟 HMD 使用新的 TrackSwap 图标，并优先采用 SteamVR 自带的 DK2 模型；虚拟设备模型缺失时使用包内回退模型。
- 设置页新增内嵌 Markdown 第三方声明视图，声明内容在编译时写入程序，避免安装目录文件被修改后影响 UI。
- 语言入口显示为“语言 / Language”，更容易被不同语言用户识别。

## 修复

- 修复 SteamVR Room Setup“建立定位”阶段把虚拟 HMD 和控制器判定为关闭的问题。
- 修复虚拟 HMD 模型相对设备原点横向偏移的问题。
- 修复配置列表出现垂直滚动条后连带产生横向滚动条的问题。
- 修复设备属性中的刷新率与追踪范围格式化错误，以及深色主题下属性文字不可读的问题。
- 修复 Runtime 配置快照在设备重连和多来源状态更新时的若干一致性问题。

## 发布与合规

- 发布构建现在强制审计第三方代码、二进制、素材、参考实现及精确版本；审计失败会停止发布。
- 自包含 Runtime 随包附带并校验对应 .NET Runtime 的许可证与第三方声明。
- 发布包和 Steam depot 排除 PDB、用户数据、诊断文件与本机路径。
