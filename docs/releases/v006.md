# TrackSwap v006

v006 把运行时路由从单一的“替换目标”扩展为三种明确模式，并加入首个可用的虚拟控制器与 OSC 输入链路。

## 主要变化

- 新增“输出为虚拟追踪器”。来源位姿和局部偏移可直接输出到稳定代理，不再必须绕经实体目标；新建配置默认使用此模式。
- 保留“替换现有设备位姿”，用于需要目标设备继续提供原有按键输入的场景。旧配置会按此模式兼容读取。
- 新增“输出为虚拟控制器”，最多创建一只左手与一只右手控制器。控制器使用 TrackSwap 自有身份和 Knuckles 兼容输入档案。
- 虚拟控制器的输入来源可选“无”或“OSC”。“无”只输出位姿并保持全部控件中立；OSC 支持 A、B、摇杆、扳机、抓握和系统键。
- 新增 OSC 设置页、无信号复位策略和约 30 Hz 的实时输入监视。固定参数地址可选中复制，但不可编辑，也不再写入运行时配置文件。
- 代理 Tracker 在直接输出模式中使用 TrackSwap 自有模型，在目标替换模式中实时切换为空模型，避免 SteamVR 重复显示代理与目标。
- 3D 预览新增来源、目标和代理模型显示控制；直接输出与虚拟控制器模式会显示实际输出模型，并改为不受方向光影响的全亮材质。
- 设备选择器与设备记录改用绿色/橙色状态点；新建配置和切换模式不再猜测默认设备。
- 设置页与 OSC 映射布局重新整理，修正分类分割线、内容留白和滚动条对齐。

## OSC 参数与兼容性

OSC 默认监听 `127.0.0.1:9015`。参数地址固定使用 `/trackswap/left/` 和 `/trackswap/right/` 前缀；旧配置中曾保存的自定义地址字段会被忽略，并在后续保存配置时移除。

虚拟控制器目前提供基础数字与模拟输入，不包含完整的 Knuckles 电容触摸数据。选择有限复位时间后，长时间未收到有效消息的对应手会自动恢复中立；选择“无”输入时 OSC 消息不会改变该手状态。

## 设备兼容性提示

具体实体设备之间的 `TrackingOverrides` 仍属于实验性用法，结果取决于 SteamVR 版本和设备驱动。Valve Index Knuckles 已在当前测试环境中验证；Pico 手柄可能忽略实体目标覆盖或无法跟随。直接虚拟追踪器和虚拟控制器模式不依赖实体目标覆盖，可优先用于不需要保留目标输入的场景。

## 安装与升级

- 推荐下载 `TrackSwap-v006-setup-win-x64.exe`，安装和卸载前必须完全退出 SteamVR。
- 安装器目前未进行代码签名，Windows 可能显示 SmartScreen 警告；可使用随附 SHA-256 文件核对下载内容。
- 从 v005 升级时可直接运行 v006 安装程序。现有目标替换配置会保留原行为。
- 仍提供完整 ZIP，供便携使用或手动部署。
- 完整卸载会删除 `%LOCALAPPDATA%\TrackSwap` 中的配置、校准档案和设备记录，请在需要时提前备份。

## 验证摘要

- 直接虚拟 Tracker、目标替换、虚拟左右控制器及 OSC 基础输入。
- OSC 超时复位、无输入模式、固定地址配置兼容与 Runtime/驱动重连。
- SteamVR 中代理模型实时显隐、控制器测试界面与 3D 模型预览。
