# TrackSwap VR v011

v011 重点加入社区本地化、运动平滑、更直观的位姿编辑与设备管理，并将产品名称统一为 TrackSwap VR。

## 当前改动

- 新增完整界面本地化系统。简体中文为官方内置语言，社区语言包可在“设置 → 语言”中刷新、切换、打开目录与导出模板，无需重启 TrackSwap VR。
- 接入 Crowdin 协作流程，提供带上下文的源字符串导出和已批准译文导入；构建会检查代码引用与简中词典，拒绝缺失、无效或未批准的翻译进入语言包。
- 新增逐路由运动平滑。位置与旋转可分别启用并独立调整 `0–100%` 整数强度，也可同步调整；滤波在原生驱动中逐帧执行，适用于虚拟追踪器、替换代理、虚拟控制器和虚拟头显。
- 位姿编辑新增欧拉角与四元数切换。默认以角度编辑欧拉角，底层仍统一保存四元数，原有配置无需迁移。
- “设置 → 设备记录”升级为“设备管理”：追踪设备和已观察到的无线接收器均可修改名称、添加备注，并可查看当前与上次观察到的连接关系。
- 设备扫描周期调整为 1 秒；无需接收器的一体机设备保持接收器为空，不会产生错误记录。
- 修复未使用 XInput 的配置仍响应输入预览、模拟阈值与触摸辅助的问题。切换或移除 XInput 路由时会清理旧输入状态。
- 翻译检查默认折叠并使用虚拟化列表，避免大量问题项导致设置页卡顿；问题表格和复制交互也已重新整理。
- TrackSwap VR 视图接入当前界面语言并移除截图功能，继续保留双眼/单眼、输出尺寸、置顶和全屏显示。
- 统一应用、Runtime、安装器、SteamVR 虚拟设备、日志和文档中的 TrackSwap VR 产品名称，同时保留旧有兼容标识与数据路径。
- 拆分仓库代理指南，分别维护 Runtime、界面、控制器输入、本地化、发布和验证规范。

## 升级提示

- v011 会继续读取 v010 的路由与用户数据；新加入的运动平滑默认关闭且强度为 `0%`。
- 驱动控制协议已更新。安装或覆盖升级后请完全重启 SteamVR，确保 Runtime 与随包驱动使用同一版本。
- 社区语言包应以 v011 模板为基础。缺失或无效的语言键会显示为 `[key]`，可在“设置 → 语言”的翻译检查中定位。
