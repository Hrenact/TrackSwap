# TrackSwap VR v013

v013 重点补全手动位姿预览、设备运动识别、诊断复现信息与 OSC 体感稳定性。

## 新增与改进

- 手动位姿的 3D 预览现在使用 SteamVR 站立空间，并显示地面参考网格及其它已连接设备，方便纯手动配置判断相对位置。
- 设备管理支持通过晃动设备识别对应卡片；各设备按当前运动幅度独立显示不干扰操作的内发光。
- 诊断包新增匿名化设备与路由拓扑、设备硬件特征、功能状态和 Runtime 状态转换日志，便于开发者在没有同款硬件时构造复现环境。
- Runtime 事件日志支持大小限制与轮换；诊断导出使用稳定化名并继续过滤真实设备路径、序列号、用户名、本机路径和网络地址。
- 设置分类重新排序，“文件管理”更名为“配置与文件”，运行模式按照头显、控制器、追踪器、替换位姿排列。

## 修复

- 修复 OSC 驱动发送阻塞可能拉长体感测试节奏并延迟预览更新的问题；测试序列现在使用独立任务和绝对时间点调度。
- 修复手动位姿预览中不同虚拟设备高度不一致、拖动 Gizmo 时模型下陷及地面高度漂移的问题。
- 修复强调色按钮和标签在部分模板下没有继承正确深色文字的问题。
- 修复设备查看在 SteamVR 停止、恢复或场景读取暂时失败时重复刷新和残留陈旧模型的问题。
- 修复设备配对关系为空时仍显示列表表头的问题。

## 工程与发布

- `v002-runtime` 开发历史迁移为当前 `main`，迁移前的稳定分支保留为 `old-v001`。
- 扩充诊断脱敏、OSC 非阻塞调度、设备运动强度与预览数学的自动化测试。
- 发布前第三方声明审计继续覆盖固定版本依赖、原生依赖、第三方素材与参考实现。
