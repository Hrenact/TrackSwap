# TrackSwap v008

v008 重点完善 XInput 自定义映射、触摸辅助与震动回传，同时收紧 Oculus Touch 兼容输入，并继续打磨设置页和运行生命周期。

## 主要变化

- 新增完整的 XInput 设置页。左右虚拟控制器分别显示映射列表、Xbox 按键图标和实时输入反馈，并支持从下拉列表选择或直接等待下一次物理按键输入。
- XInput 映射、模拟输入触发阈值和震动方式会自动保存；左右手绑定可分别恢复默认，并通过带系统提示音的深色确认弹窗防止误操作。
- 新增拇指与食指触摸辅助。每只手可以选择辅助按键以及“默认接触 / 默认抬起”，按住辅助键时临时反转状态；真实按键映射始终拥有更高优先级。
- 新增 SteamVR 震动回传到 XInput 手柄，支持“保留手别”、“保留手别（镜像）”与“统一震动”，并在手柄断开、路由切换或 Runtime 退出时立即停止马达。
- XInput 采样、界面观察和驱动通信改为相互独立；高回报率手柄或较慢的驱动 IPC 不再把设置页实时预览拖慢到数秒一次。
- OSC 接收器改为由正在使用 OSC 的虚拟控制器配置自动启停，移除单独的启用复选框；监听地址、端口和复位时间仍实时应用。

## 控制器兼容性

- 虚拟控制器的扳机与抓握只公开连续值和触摸状态，不再发布 Oculus Touch 不具备的合成 Click 输入。
- 两只手的菜单按键状态会以逻辑 OR 合并到左手 System，避免一侧松开时覆盖另一侧仍按住的状态。
- 每只虚拟控制器均发布独立的 `/output/haptic`，游戏仍可分别请求左、右手震动，再按用户选择映射到 XInput 的两颗马达。
- 保留 TrackSwap 自有设备身份和 Oculus Touch 兼容模式，不冒用 Oculus/Meta 序列号，也不附带游戏专用默认绑定。

## 界面与可靠性

- 新增贯穿窗口底部的紧凑状态栏，集中显示 SteamVR、Runtime、OSC 与 XInput 的可用、等待和健康状态；配置数量限制仍保留在侧边栏新增按钮旁。
- XInput 实时反馈整合到按键图标背景中；摇杆图标直接随二维输入移动并由背景裁切，按下状态保持独立显示。
- 统一设置页滑块、下拉框、图标预览和确认弹窗的 Dark Utility 样式，修复滚动列表边缘误触发页面滚动、紧凑文本被箭头遮挡以及控件被父布局拉高的问题。
- OpenVR Utility 客户端会在 SteamVR 退出事件到达时主动释放，避免 SteamVR 强制终止手动打开的 TrackSwap；“跟随 SteamVR 启停”关闭时也会清理应用清单注册。
- 修复进入设置后返回错误配置编辑页、Runtime 配置已经出现但等待界面未消失，以及多个实时状态显示不同步的问题。
