# TrackSwap v007

v007 重点完善虚拟控制器、实时配置编辑和 3D 位姿调整，并把直接虚拟 Tracker 与目标替换代理拆分为明确的设备身份。

## 主要变化

- 新增 XInput 控制输入。标准 Xbox 手柄会按左右两侧拆分摇杆、肩键、扳机、面键和菜单键，驱动对应的虚拟左右手控制器。
- 虚拟控制器改用 TrackSwap 自有身份与 Oculus Touch 兼容档案，提供 X/Y、A/B、摇杆、扳机、抓握、菜单、触摸状态以及标准 31 骨骼手部输入。
- 根据按钮、摇杆和模拟量活动合成 Touch 风格的拇指、食指与其余手指动作，并加入连续弯曲、张合与平滑过渡。
- 新增虚拟控制器手部选择优先级设置，默认保持 SteamVR 标准值 `0`；允许高级用户按需调整并恢复默认。
- 配置编辑改为近乎全局实时应用：完整选择立即提交，位姿数值短暂防抖，Gizmo 松开与重置立即保存；移除路由级“应用更改”和“重新读取”按钮。
- 新建配置不再预选模式或设备。切换模式时会清空对应专用字段并显示“请选择”，防止误用上一个模式的选择。
- 局部位置偏移统一以厘米显示、保存和编辑；输入框仅接受阿拉伯数字、小数点与必要的前导负号。
- 3D 预览新增“隐藏 / 移动 / 旋转”调整工具，可沿虚拟输出设备的局部坐标直接拖动位姿，按住 Shift 可精调；默认隐藏调整工具。
- 预览模型改为全亮不透明材质，修复纹理半透明问题，并可分别隐藏来源、目标或始终显示代理模型。
- 设备枚举改为复用进程级 OpenVR Utility 会话，减少 SteamVR 反复重新加载输入绑定导致设置或控制器界面异常的情况。
- Runtime 与 TrackSwap 跟随 SteamVR 的启停流程得到修正；关闭 SteamVR 后只等待实际存在的待处理配置，不再固定延迟退出或重复拉起 UI。
- Runtime 配置尚未读取时显示明确的等待状态，不再把暂时未连接误报为“暂无配置”。

## 设备身份与容量

- 配置列表总上限从 8 条提高到 16 条，侧边栏显示当前数量与 `16` 条总上限。
- “输出为虚拟追踪器”现在使用独立的 `TRKSWAP-TRACKER-00` 至 `TRKSWAP-TRACKER-15`。
- “替换现有设备位姿”继续使用内部 `TRKSWAP-PROXY-00` 至 `TRKSWAP-PROXY-15`，仅这些代理会参与 `TrackingOverrides` 静态映射。
- 两种普通模式没有各自的数量配额，只受 16 条配置总数限制；虚拟控制器仍固定为左、右各一只。

## 配置与界面改进

- 设置页重新划分运行环境、SteamVR、设备记录、OSC 与高级选项，并补充设备记录列表及清理操作。
- 设备选择器和设备记录实时更新，以绿色和橙色状态点区分在线与离线设备。
- 路由同步状态集中显示在配置页标题区域，修复待删除、待映射与无静态映射配置之间的状态冲突。
- 无效配置使用统一中文深色弹窗说明原因；修复来源与目标相同时配置被错误标记为待删除的问题。
- 高级选项可以允许多条配置复用同一位姿来源，同时继续阻止重复手别、目标冲突、槽位冲突与路由循环。
- OSC 页面改为固定只读参数参考并实时应用接收设置，加入 30 Hz 布尔、标量与摇杆二维状态监视。

## 升级注意事项

- v007 将局部位置数值直接解释为厘米，不对旧数值执行自动换算。升级后请检查现有配置的 X/Y/Z 偏移。
- 旧版直接输出使用 `TRKSWAP-PROXY-XX`。升级后相同配置会输出为新的 `TRKSWAP-TRACKER-XX`，SteamVR 会将其视为新设备，可能需要重新分配腰部、脚部等 Tracker 角色。
- 目标替换配置仍使用原有 `TRKSWAP-PROXY-XX` 身份和静态映射，不需要改选目标。
- 安装器仍未进行代码签名，Windows 可能显示 SmartScreen 警告；可使用随附 SHA-256 文件核对下载内容。

## 验证摘要

- Windows x64 托管项目、原生 OpenVR 驱动、安装器注册与完整发布包构建。
- Protocol、Runtime、位姿数学、手部骨骼动画、OSC 与 XInput 映射自动化测试。
- SteamVR 中虚拟控制器基础输入、Touch 兼容测试界面、骨骼动画、模型显隐与实时位姿调整。
- Runtime/TrackSwap 跟随 SteamVR 启停、配置自动应用、待映射与待删除收敛流程。
