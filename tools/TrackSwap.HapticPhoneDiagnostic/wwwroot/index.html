结果怎么读

“UDP 已收到”证明 TrackSwap 的 OSC 发送路径和端口有效；“网页已收到”证明桥接正常；“浏览器已接受”仅表示 navigator.vibrate() 接受了请求，系统静音、勿扰模式或硬件限制仍可能阻止实际振动。

网页 API 只能控制振动/暂停时长。这里用脉冲疏密近似频率、用占空比近似强度，不能把手机当作精确的触觉执行器。
